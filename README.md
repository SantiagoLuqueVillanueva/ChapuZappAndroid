# ChapuZapp · Android

App Android de ChapuZapp: busca y contrata profesionales por sector, consulta sus horarios y tarifas, chatea con ellos y gestiona tus citas. Proyecto intermodular de 2º DAM (Sanchez, Santi y Guti).

## Estado
Esqueleto con navegación inferior entre Inicio, Citas, Mensajes y Perfil. Aún sin datos, red ni base de datos local.

## Tecnologías
Kotlin 2.2.10 · Jetpack Compose + Material 3 · Navigation Compose 2.10.2 · AGP 9.2.1 · Gradle 9.4.1 · JDK 21

SDK: minSdk 35 · targetSdk 36 · compileSdk 37.1

## Cómo ejecutarlo
1. Clona el repo: `git clone https://github.com/SantiagoLuqueVillanueva/ChapuZappAndroid.git`
2. Ábrelo en Android Studio y espera a que sincronice Gradle.
3. Ejecuta `app` en un emulador o móvil con Android 15 (API 35) o superior.

## Git
Ramas `main`, `develop` y una por persona (`guti`, `santi`, `sanchez`). Los cambios entran a `develop` por Pull Request y los commits llevan una frase clara de lo hecho.
